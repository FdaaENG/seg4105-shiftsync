# ShiftSync

**Constraint-Based Employee Scheduling System**  
SEG4105 term project · Phase 2: Design Deliverables · Group: 19

## Overview

ShiftSync is a scheduling application for a three-store retail and pharmacy chain with approximately 60 employees. It uses constraint programming with Google OR-Tools CP-SAT to generate weekly employee schedules.

Schedules account for employee availability, time-off requests, roles and skills, required staffing, and working-hour limits. Managers review and edit draft schedules before publishing. Employees can view their shifts and receive updates.

## Project Objectives

- Reduce schedule creation time from approximately six hours to under one hour per store per week.
- Eliminate hard-rule violations in published schedules.
- Reduce overtime costs by 15%.

## Key Capabilities

- Generate weekly schedules while considering staffing and employee constraints.
- Let managers review and edit schedules before publication.
- Let employees view their shifts and receive schedule updates.
